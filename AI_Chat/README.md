# CodeMate - 本地 AI 代码开发助手

基于 PyQt5 的桌面代码开发工具，集成本地 LLM (llama.cpp) 的 AI 辅助能力。类似 TRAE CN 的桌面 IDE 体验，完全本地运行，无需浏览器。

## ✨ 功能特性

### 🖥️ 桌面 IDE 界面
- **VS Code 风格** — 三栏布局：左侧文件树 + 中间编辑器 + 右侧 AI 助手
- **深色主题** — 护眼的深色界面
- **多标签编辑** — 支持同时打开多个文件
- **语法高亮** — Python 语法高亮（可扩展其他语言）
- **行号显示** — 带行号的代码编辑器
- **括号自动补全** — 智能括号匹配

### 🤖 AI 代码助手
- **流式对话** — 实时流式输出，边想边说
- **代码解释** — 详细解释代码工作原理
- **代码审查** — 检查质量、Bug、性能、安全问题
- **代码重构** — 优化代码结构和可维护性
- **Bug 修复** — 分析问题并给出修复方案
- **测试生成** — 自动生成单元测试
- **上下文感知** — 自动读取当前打开的文件作为 AI 上下文

### 📁 文件管理
- 资源管理器树状视图
- 文件/文件夹新建、删除、重命名
- 右键上下文菜单
- 双击打开文件

### 💻 集成终端
- 内置 PowerShell 终端
- 支持命令历史（上下键）
- F5 直接运行当前 Python 文件
- Ctrl+` 快速切换终端显隐

### ⌨️ 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存文件 |
| `Ctrl+W` | 关闭标签 |
| `` Ctrl+` `` | 切换终端 |
| `F5` | 运行当前文件 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |

## 🚀 快速开始

### 前置要求
- Windows 10/11
- Python 3.8+
- PyQt5
- llama-server 运行在 8080 端口

### 方式一：一键启动（推荐）

双击 `start-all.bat`，会自动：
1. 后台启动 llama-server（加载 IQ2_M 模型）
2. 等待模型加载
3. 启动 CodeMate 桌面程序

### 方式二：分步启动

1. **启动 LLM 服务**（在上一级目录）
   ```
   运行 run.bat 选择模型
   ```

2. **启动 CodeMate**
   ```
   cd codemate-desktop
   start.bat
   ```

### 手动安装依赖
```bash
pip install PyQt5 requests
```

## 🎯 使用指南

### 基本工作流

1. **打开/创建文件** — 在左侧资源管理器中双击文件，或右键新建
2. **编写代码** — 在中间编辑器中编写代码
3. **AI 辅助** — 使用右侧 AI 面板的快捷按钮：
   - 📖 **解释** — 解释当前文件的代码
   - 🔍 **审查** — 审查代码质量和问题
   - ♻️ **重构** — 优化代码结构
   - 🐛 **修 Bug** — 帮助修复问题
   - 🧪 **测试** — 生成单元测试
4. **运行测试** — 按 `F5` 运行当前 Python 文件
5. **终端操作** — 按 `` Ctrl+` `` 打开终端执行命令

### AI 上下文

AI 助手会自动将当前打开的文件内容作为上下文传入，所以你只需要打开文件后点击快捷按钮即可。

也可以直接在聊天框中提问，AI 会参考当前文件的内容来回答。

## ⚙️ 配置

### 修改 LLM 服务器地址

设置环境变量 `LLM_SERVER_URL` 来修改默认地址：

```batch
set LLM_SERVER_URL=http://192.168.1.100:8080
```

或者直接修改 `app.py` 中的默认值。

### 工作区目录

默认工作区是 `codemate-desktop/workspace/`，可以在 `app.py` 中修改。

## 🔧 扩展开发

### 添加新的语言高亮

在 `widgets/code_editor.py` 中添加新的 `SyntaxHighlighter` 子类。

### 添加新的 AI 动作

在 `widgets/ai_panel.py` 的 `do_code_action` 方法和 `core/prompts.py` 中添加新模板。

### 自定义主题

修改 `widgets/code_editor.py` 顶部的 `THEME` 字典。

## ❓ 常见问题

**Q: 启动后 AI 面板显示 "LLM 未连接" 怎么办？**
A: 请确保 llama-server 已启动并监听 8080 端口。可以在上一级目录运行 `run.bat` 启动模型服务。

**Q: 可以使用其他模型吗？**
A: 可以！只要 llama.cpp 支持的 GGUF 格式模型都可以。修改 llama-server 的启动参数即可。

**Q: AI 响应很慢怎么办？**
A: IQ2_M 量化级别推理速度较慢。如果显存足够，建议使用 Q4_K_M 或更高级别的量化模型。

**Q: 支持哪些编程语言？**
A: 当前内置 Python 语法高亮。其他语言可以正常编辑和使用 AI 助手，只是没有语法高亮。

**Q: 数据会上传到云端吗？**
A: 不会！所有 AI 推理都在本地运行，代码和对话数据都不出本地。
